# Flowcess

Vocal-Recording-App im Stil von Apple Sprachmemos – für Rap & Gesang.

**App öffnen:** https://kreniedsch.github.io/Flowcess/

Auf dem iPhone: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Funktionen: Beat laden (BPM, Tonart, Taktraster automatisch), Vocals aufnehmen, Takes mit Fader/Mute/Solo, Songteile (Intro, Verse, Hook …), Lyrics- und Live-Modus, Tempo/Tonart ändern, Vocal-FX (EQ, Kompressor, Hall, Echo, Auto-Tune), Beat aus Vocal entfernen, Mix-Export als WAV.
